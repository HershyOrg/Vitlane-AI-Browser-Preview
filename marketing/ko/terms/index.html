이용·결제 기준

상품 조사와 PayPal Live Pilot·Sandbox·GIWA TEST의 구분된 구매 경로를 안내합니다. 결제와 조달은 앱에서 사용자의 명시적인 승인을 거쳐야 합니다.

1. 상품 조사와 현재 제공 범위

Vitlane은 AI로 상품을 조사하고 비교합니다. 앱에서 이용 가능한 PayPal Live Pilot은 미국 배송지 대상 실제 주문과 배송을 지원하며 승인·청구·환불 통화는 USD입니다. PayPal Sandbox와 GIWA Testnet은 별도의 테스트 선택지로, 실제 판매처 주문이나 실물 배송을 만들지 않습니다. GIWA 운영망과 USDC 결제는 아직 제공하지 않습니다.

2. 상품 선택과 구매 승인

조사 결과는 추천이며 주문이 아닙니다. 구매 준비 시 가격·재고·배송·세금을 다시 확인합니다. 사용자는 상품을 선택하고 주문서에 표시된 상품·옵션·수량·배송지·총액·대행 수수료·결제수단을 명시적으로 승인합니다. 상품 선택만으로 결제가 승인되지 않습니다. 외부 구매로 표시된 상품은 Vitlane 주문·결제 흐름 밖의 판매처 사이트에서 구매합니다.

3. PayPal 승인과 지갑 서명

PayPal에서는 주문 전체 금액의 결제 승인을 먼저 진행하며, 이는 실제 청구나 판매처 구매와 별개입니다. 승인한 조건 안에서 조달을 진행할 때 해당 판매처 주문의 금액을 청구합니다. GIWA Testnet에서는 지갑 소유 확인, tVITUSD 받기, 정확한 결제 한도 승인과 결제 제출이 서로 다른 행동이며 사용자가 직접 서명합니다. Vitlane은 지갑 private key나 무제한 allowance를 요구하지 않습니다.

4. 가격·수수료와 TEST 자산

주문서는 승인 전에 상품 금액·배송비·세금·Vitlane 대행 수수료를 금액과 통화로 표시합니다. PayPal Live는 실제 USD를 사용하고 PayPal Sandbox는 실제 돈을 이동하지 않습니다. GIWA Testnet의 6-decimal tVITUSD에는 경제적 가치, USD backing이나 현금 상환 권리가 없습니다. Test ETH는 네트워크 수수료용이며 주문 금액과 별개입니다.

5. 주문 처리와 기록

PayPal Live Pilot에서는 운영자가 사용자의 승인 범위 안에서 판매처 구매를 수행하고 앱에 주문·배송 진행을 기록합니다. 새로운 중대한 판매처 조건이 생기면 진행 전에 사용자 응답을 받습니다. Vitlane 주문 기록은 판매처 영수증을 대체하지 않습니다. Sandbox와 Testnet의 주문 처리는 SIMULATED이며 TEST 영수증은 실구매 증빙이나 배송 약속이 아닙니다.

6. 취소와 환불

취소·환불은 주문서에 표시된 판매처 주문 전체 단위로 처리하며, 그 안의 일부 상품이나 수량만 별도로 처리하지 않습니다. 해당 청구나 조달 효과가 시작되기 전에는 그 판매처 주문의 취소를 요청할 수 있습니다. 조달 후에는 하자·오배송·미수령·조달 실패 등 지원하는 사유의 환불 요청을 앱에서 검토합니다. 승인된 환불 금액에는 해당 판매처 주문의 금액과 배분된 대행 수수료가 포함됩니다. PayPal에서는 청구 전 금액을 해제하거나 청구된 금액을 PayPal로 환불하며, Sandbox 환불은 모의 처리입니다. GIWA Testnet 환불은 TEST 정산 규칙에 따른 무가치 tVITUSD 반환입니다. 요청 접수나 처리 중 상태는 환불 완료를 뜻하지 않습니다.

승인 전에 상품·옵션·수량·배송정보·금액과 선택한 Live 또는 TEST 결제수단을 확인해 주세요. 지갑 행동은 네트워크·contract·수량도 확인해야 합니다. 결제나 서명 요청이 앱의 안내와 다르면 중단하고 고객 대화로 문의해 주세요. 지원 메시지에 지갑 private key나 결제 인증정보를 보내지 마세요.
