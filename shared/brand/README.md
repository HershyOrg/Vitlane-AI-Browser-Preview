# Brand 공유 source

Marketing, 제품 App과 operator가 함께 쓰는 canonical brand geometry를 둔다.

- `vitlane-lane-mark.svg`: Lane Signal master mark
- consumer는 이 파일을 직접 복사하지 않고 각 build의 design asset generator가
  만든 산출물을 사용한다.
- 색과 크기는 consumer의 semantic token이 소유한다. SVG의 stroke 색은 concept
  문서에서 source 자체를 열 때 보이도록 한 기본 preview 값이다.
